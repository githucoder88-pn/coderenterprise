# Changelog

## 1.0.0 (current)
- Initial enterprise backend with six AI providers, resilience stack,
  multi-agent orchestration, knowledge/workspace engines, extension
  marketplace, clustering primitives, and billing/analytics.
- Mobile, web dashboard, CLI, desktop, and VS Code clients sharing the
  same REST/SSE API.
- Zod-validated config, JWT+RBAC+API-key auth, AES-GCM secret storage.
- BullMQ workers for indexing, summarization, and billing sync.
