# Configuration

User-configurable settings (declared in `package.json` contributes.configuration):

| Setting | Type | Default | Purpose |
|---------|------|---------|---------|
| `coder.apiUrl` | string | `http://localhost:3000/api/v1` | Backend URL |
| `coder.apiKey` | string | `''` | API Key |
| `coder.defaultProvider` | string | – | Default provider |
| `coder.defaultModel` | string | – | Default model |
| `coder.inlineCompletions` | boolean | `true` | Toggle inline completions |
| `coder.telemetry` | boolean | `true` | Telemetry |
| `coder.theme` | `'auto'|'dark'|'light'` | `auto` | UI theme for webview |

Keyboard shortcut: `Ctrl+Shift+C` / `Cmd+Shift+C` → open chat.
