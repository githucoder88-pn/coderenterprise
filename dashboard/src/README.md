# src

**Purpose:** Dashboard source (Next.js 15 App Router, React 19, TanStack Query).

## Subdirectories

| Path | Purpose |
|------|---------|
| [app/](app/) | Next.js App Router pages. |
| [components/](components/) | React components. |
| [hooks/](hooks/) | TanStack Query hooks against the backend API. |
| [lib/](lib/) | API client + utility helpers. |
| [providers/](providers/) | React context providers (query, theme). |
| [stores/](stores/) | Zustand stores (auth, UI). |
| [styles/](styles/) | Tailwind/global styles. |
| [tests/](tests/) | Vitest tests. |
