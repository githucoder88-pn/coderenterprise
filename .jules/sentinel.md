## 2025-02-14 - Flawed Path Traversal Check Using .startsWith()
**Vulnerability:** A path traversal vulnerability existed in the `safePath` validation function (`src/tools/filesystem/filesystem.tool.ts`) which relied on `resolved.startsWith(resolve(base))`. An attacker could supply a target like `../workspace-secrets/key.txt` (when `base` is `/app/workspace`). The resolved path `/app/workspace-secrets/key.txt` incorrectly passes the `.startsWith()` check because `/app/workspace-secrets` starts with `/app/workspace`.
**Learning:** Checking for directory containment using simple string `.startsWith()` on resolved paths is unsafe and can be bypassed if the restricted base path is a prefix of another sibling directory. This pattern exists and may appear in other node.js applications.
**Prevention:** To prevent directory traversal when validating paths, one must use `path.relative` to ensure the path doesn't navigate up (`..`) and checking `isAbsolute` to prevent cross-drive traversal.
